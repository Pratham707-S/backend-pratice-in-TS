# 📘 Day 2: PostgreSQL & SQL Mastery
⏱ **Video Range:** `5:07:05` - `9:14:05` (~4 Hours)

### 🎯 Topics Covered:
1. **01-postgres-basics-and-setup** (`5:07 - 5:50`)
   - PostgreSQL install & connection
   - Database & Schema creation (`CREATE DATABASE`, `CREATE SCHEMA`)
   - Creating tables
2. **02-data-types-and-constraints** (`5:50 - 6:30`)
   - SQL Data types: VARCHAR, INT, BOOLEAN, TIMESTAMP, etc.
   - Constraints: PRIMARY KEY, UNIQUE, NOT NULL, CHECK, DEFAULT
   - NULL vs empty string vs 0
3. **03-basic-crud-queries** (`6:30 - 7:44`)

   - `SELECT` columns & `WHERE` filters (`AND`, `OR`, `NOT`, `LIKE`, `IN`, `BETWEEN`)
   - `ORDER BY`, `LIMIT`, `OFFSET` (Pagination)
   - `UPDATE` & `DELETE` queries
   - `RETURNING` clause
4. **04-relationships-and-joins** (`7:44 - 8:34`)
   - Foreign Keys & Data integrity
   - 1-to-many & Many-to-many relationships
   - `INNER JOIN`, `LEFT JOIN`, table aliases
5. **05-aggregations-and-subqueries** (`8:34 - 8:58`)
   - Aggregate functions: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
   - `GROUP BY` and `HAVING` filters
   - `COUNT(DISTINCT ...)` & Subqueries
6. **06-indexes-and-transactions** (`8:58 - 9:14`)
   - SQL Indexes for performance
   - ACID Transactions (`BEGIN`, `COMMIT`, `ROLLBACK`)
